# Queenshop — Fashion Wanita

Source code website toko fashion wanita Queenshop.

## Fitur

- Katalog produk, pencarian, dan filter kategori.
- Detail produk dengan pilihan ukuran dan motif/warna.
- Keranjang belanja dengan pengaturan kuantitas.
- Promo kulot: 3 pcs Rp100.000.
- Paket 3 atasan Rp100.000.
- Checkout dan formulir alamat pengiriman.
- Pilihan QRIS, transfer bank, e-wallet, dan COD dalam mode simulasi.
- Konfirmasi pesanan.
- Tampilan responsif untuk desktop dan perangkat seluler.

## Menjalankan secara lokal

Pastikan Node.js dan npm sudah terpasang.

```bash
npm install
npm run dev
```

Untuk membuat build produksi:

```bash
npm run build
npm run preview
```

## Catatan

Data produk, foto, varian, dan harga mengikuti materi katalog yang diberikan dan menggunakan foto alternatif. Harga setelan pendek belum tersedia. Pilihan pembayaran belum terhubung ke payment gateway dan tidak memproses uang sungguhan. Integrasi pembayaran, validasi stok, ongkos kirim aktual, dan pengelolaan pesanan perlu ditambahkan sebelum dipakai untuk transaksi riil.
